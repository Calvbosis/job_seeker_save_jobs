Dev notes: save heart animation

Tap the heart in the prototype above to see it in action. Everything is plain CSS keyframes triggered by a class on the button, so there's no animation library to add.

1. What it does

  • Save: the heart fills red and pops, a faint ring ripples out, and 6 small dots burst away. All done in about 420ms. Then the snackbar shows "Job saved".
  • Unsave: the heart goes back to the grey outline with a tiny settle (no burst). The snackbar shows "Removed from saved jobs".

2. Markup

One button holding the heart SVG (two paths: a fill underneath and an outline on top), one ring and six dots. The ring and dots sit invisible until the animation runs.

<button class="save"
  [class.is-saved]="saved"
  [class.anim-save]="anim === 'save'"
  [class.anim-unsave]="anim === 'unsave'"
  (click)="toggleSave()"
  (animationend)="anim = null"
  [attr.aria-pressed]="saved"
  [attr.aria-label]="saved ? 'Remove from saved jobs' : 'Save job'">
  <svg viewBox="0 0 24 24" aria-hidden="true">
    <path class="fill" d="…heart path…" />
    <path class="outline" d="…heart path…" />
  </svg>
  <span class="ring"></span>
  @for (a of [30, 90, 150, 210, 270, 330]; track a) {
    <span class="dot" [style.--a]="a + 'deg'"></span>
  }
</button>

3. Animation specs

PartMovementDuration and easing
Heart (save)Scale 0.8 → 1.15 → 1350ms, cubic-bezier(.3, 1.4, .5, 1)
RingScale 0.5 → 1.5, opacity 40% → 0400ms, ease-out
Dots ×6Move 8px → 19px from centre, shrink to 0.2, fade out420ms, cubic-bezier(.2, .7, .3, 1)
Heart (unsave)Scale 0.9 → 1160ms, ease-out

The dots are 4px circles spaced 60° apart, starting at 30° so none fire straight up. They alternate between the two reds below.

4. The CSS

.save .fill    { fill: #BA1A1A; opacity: 0; transition: opacity 120ms; }
.save .outline { fill: none; stroke: #475467; stroke-width: 1.8; }
.save.is-saved .fill    { opacity: 1; }
.save.is-saved .outline { stroke: #BA1A1A; }

.save.anim-save svg   { animation: heart-pop 350ms cubic-bezier(.3,1.4,.5,1); }
.save.anim-unsave svg { animation: heart-settle 160ms ease-out; }
.anim-save .ring { animation: heart-ring 400ms ease-out; }
.anim-save .dot  { animation: heart-dot 420ms cubic-bezier(.2,.7,.3,1) forwards; }

@keyframes heart-pop    { 0% { transform: scale(.8) } 55% { transform: scale(1.15) } 100% { transform: scale(1) } }
@keyframes heart-settle { 0% { transform: scale(.9) } 100% { transform: scale(1) } }
@keyframes heart-ring   { 0% { transform: scale(.5); opacity: .4 } 100% { transform: scale(1.5); opacity: 0 } }
@keyframes heart-dot {
  0%   { transform: rotate(var(--a)) translateY(-8px)  scale(1);  opacity: 1 }
  100% { transform: rotate(var(--a)) translateY(-19px) scale(.2); opacity: 0 }
}

@media (prefers-reduced-motion: reduce) {
  .save svg, .ring, .dot { animation: none !important; }
}

The ring and dots are absolutely positioned at the centre of the button with opacity: 0 by default. See the prototype source for the full positioning styles.

5. Component logic

saved = false;
anim: 'save' | 'unsave' | null = null;

toggleSave() {
  this.saved = !this.saved;
  this.anim = null;                       // clear first so a fast second tap replays
  requestAnimationFrame(() => {
    this.anim = this.saved ? 'save' : 'unsave';
  });

  this.snackBar.open(
    this.saved ? 'Job saved' : 'Removed from saved jobs',
    undefined,
    { duration: 4000 }
  );

  // call the save / unsave API here
}
  • Update saved straight away on tap. Don't wait for the API or the animation to finish.
  • If the API call fails, set saved back without animation and show an error snackbar.
  • MatSnackBar.open() closes any open snackbar for us, so tapping quickly never stacks them. Use the default position (bottom centre). If there's a bottom nav, the snackbar must sit above it.

6. Hover and press

A 40px circle sits behind the heart as a state layer, the same pattern as Angular Material icon buttons. It uses the heart's current colour at low opacity, so it's grey when unsaved and red when saved.

.save::before {
  content: ""; position: absolute; inset: 0; border-radius: 50%;
  background: #475467; opacity: 0; transition: opacity 150ms;
}
.save.is-saved::before { background: #BA1A1A; }
.save:hover::before    { opacity: .08; }
.save:active::before   { opacity: .12; }

/* touch screens: no sticky hover after a tap */
@media (hover: none) {
  .save:hover::before  { opacity: 0; }
  .save:active::before { opacity: .12; }
}

If the button is built with mat-icon-button, this state layer comes for free. Just make sure its colour follows the saved state.

8. Checklist

  • Tap target is 40 × 40px with the 24px heart centred.
  • Keyboard focus ring is visible.
  • Hover circle shows on desktop and doesn't stick after a tap on mobile.
  • Reduced motion turns off all animation, but the state still changes.
  • Tapping fast restarts the animation instead of queuing it.
  • The heart's state matches the saved jobs list after a page refresh.
